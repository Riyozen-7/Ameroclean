Size Guide & Measurements

Every Amero piece is cut honestly and runs one piece per size per drop. The chest and length below are in inches, measured flat. If you are between sizes, choose the roomier option — these are everyday, layering-friendly fits.

How to measure

  • Chest: measure around the fullest part of your chest, keeping the tape level.
  • Length: from the top of the shoulder seam down to the hem.
  • Knit/stretch: fall in love with the fit, not the tag — if in doubt, size up.

Because we run one piece per size, same-size exchanges are only possible while that piece is still available. Order early if a size matters to you.
